Dynamic Web Templates

More importantly MS Expression Web has a feature that does not have a match in any web editing software that I have investigated to date. And that is a 'template' system that is similar to MS Word document templates (.dot). You can create a template file, e.g. maste.dwt, that sets out the basic structure of ALL your web pages, except the specific page contents of each.

You can then use that template ('master.dwt') in all your web pages, to automatically create the bulk of the page's code without you having to physically type it. But you do have to manually type any page content that is specific to each web page. Of course MS Expression Web sets all this up for you when you use its 'site wizard' tool to create an entire working website 'stub' based on the template you select.

If you want to create a new page then you can right mouse click on 'master.dwt' and select 'New from Dynamic Web Template' from the popup menu. After which Expression web will create a new HTML file with most of the new page's content filled in for you from the code in 'master.dwt'.

Then, when you make changes to 'master.dwt' and save your canges, Expression Web runs through all the web pages in your website and updates them for you! And even better! If you rename a file or move it from one folder to another then Expression Web does a text searche through ALL your web pages, looking for any image links, hyperlinks or includes (that use that renamed or moved file) and updates them accordingly so that you do not have any broken links in your web pages.

EDITABLE AND NON EDITABLE REGIONS

Expression web creates editable and non-editable regions in your web pages by means of HTML comments that are ignored by web browsers. Here are examples...

This is an editable region of the web page, whose name is 'CustomContent'. You type the page's specific content between <!-- #BeginEditable "CustomContent" --> and <!-- #EndEditable -->. 

<!-- #BeginEditable "CustomContent" -->
<p>*******************************************************</p>
<p>*******************************************************</p>
<p>Insert content here</p>
<p>*******************************************************</p>
<p>*******************************************************</p>
<!-- #EndEditable -->

This is also another defined region of the web page code, named 'Footer'. However this region is NOT editable! Note the absence of the keyword 'Editable'.

Now notice that regions that you are not permitted to edit (between <!-- #BeginEditable "CustomContent" --> and <!-- #EndEditable -->) have a yellowish text background color when you view these files in Expression Web. While the regions that you ARE permitted to edit have no background color.

HTML CODE

HTML code looks like this: 

		<h1>Grant from Elders</h1>
		<p>The Mill House Committee, management and the community would like to thank Elders for their generous grant to our organisation.</p>
		<p><a href="images/EldersGrant.jpg"><img src="images/EldersGrant.jpg" alt="EldersGrant.jpg" width="300"/></a></p>
		<h1>Everyone is welcome at Mill House 😊</h1>
		<h2>Mill House Activities</h2>
HTML uses a begin tag, e.g. <h1>, and an end tag, e.g. </h1>. The tags themselves are not displayed in the web browser. Only the text or images etc. between them. The tags tell the web browser how to render the text, e.g. a big or a small font, on a new line or the same line as previous tags, text color, etc.

This paragraph, for example, is created by enclosing this text in p tags:

<p>This paragraph, for example, is created by enclosing this text in p tags:</p>

So it is relatively easy for even raw beginners to edit basic text content in a web page using simple tags like these. For more details on how to use HTML tags refer to HTML for beginners

INLINE CSS

E.G. <table border="0" cellpadding="0" cellspacing="0" style="width:100%;">

Specifically the 'style="width:100%;' property inside the <table .....> tag. The 'width:100%;' part is the actual CSS code. The 'style' property is how to apply the CSS code to the HTML tag.

CSS takes a bit more time to wrap your head around and become confident with it. But you novices will not need to use it much or at all for the most part when editing basic HTML content. But if novices want to try and learn it then they shuld refer to this guide: CSS for beginners

JAVASCRIPT CODE

JavaScript code is always placed between the following two tags: <script type="text/javascript"> and </script>

JavaScript is full programming language and takes a great deal more effort to master. So novices should not try to edit anything between these tags. Typing HTML code between these tags, for example, will generate a syntax error, as the web browser is rendering the web page. At this point the web browser will stop rendering the page, resulting in the web page appearing messed up in the web browser.

Novices sould steer well clear of JavaScript code.

PHP CODE

PHP code is always placed between the following two tags: <?php; and ?>

PHP is also full programming language and also takes a great deal more effort to master. So novices should not try to edit anything between these tags. Typing HTML code between these tags, for example, will also cause a syntax error at the web server, which will then send a black screen with a desription of the syntax error.

Novices sould steer well clear of PHP code.
